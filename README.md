# Movie Review Admin Site

This repository contains the administrative portion of a larger movie review web application. The final application is a project for my Web Application Programming course at NSCC. 

## Overview

The Movie Review Admin Site will provide the tools needed to maintain the platform behind the scenes. Administrators can manage catalog content, review submissions, user accounts, and other site settings from a central interface. Movie critics will also be allowed to add/modify their reviews.

This project is part of a larger Web Application Programming assignment focused on building a full-stack application for movie reviews, with this repository handling the admin-facing functionality.

## Features

- Dashboard for platform overview
- Manage movies, genres, and metadata
- Moderate reviews and user submissions
- Manage user accounts and permissions
- Secure admin authentication
