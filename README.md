# Movie Review Admin Site

This repository contains the administrative portion of a larger movie review web application. It is designed to support the management and moderation of the main site, including movie data, user activity, reviews, and content administration.

## Overview

The Movie Review Admin Site provides the tools needed to maintain the movie review platform behind the scenes. Administrators can manage catalog content, review submissions, user accounts, and other site settings from a central interface. Movie critics will also be allowed to add/modify their reviews 

This project is part of a larger Web Application Programming assignment focused on building a full-stack application for movie reviews, with this repository handling the admin-facing functionality.

## Features

- Dashboard for platform overview
- Manage movies, genres, and metadata
- Moderate reviews and user submissions
- Manage user accounts and permissions
- Secure admin authentication
